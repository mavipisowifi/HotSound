2. WHAT HOTSound IS

HotSound is a desktop soundboard for Windows. It shows a PC keyboard
layout on screen; each key can hold a sound, and pressing that key plays
it. It runs entirely on your own computer. There are no user accounts, no
sign-in, and no server component.

7. PRIVACY POLICY

7.1 What is collected
    Nothing. HotSound has no telemetry, no analytics, no usage reporting
    and no accounts. The developer receives no information about you or
    about how you use the software.

7.2 What the software reads
    Only the audio files you explicitly select, and its own profile and
    settings files described below. It does not scan your disks and does
    not read any file you have not chosen.

7.3 What the software writes
    Two small text files in your Windows application-data folder, under
    HotSound: a profile holding your key assignments, and a settings file
    holding the location of that profile. If you use "Save profile", a
    profile is written to the location you pick instead. Nothing else is
    written anywhere.

7.4 Network activity
    The software itself makes no network requests: it does not check for
    updates and does not contact any server. It contains one web link, to
    the developer's GitHub page. That link opens in your own browser only
    when you click it, and once open it is governed by GitHub's own terms
    and privacy policy.

7.5 Uninstalling
    Uninstalling removes the application. Your profile and settings are
    deliberately left behind so that reinstalling does not lose your setup.
    Delete the HotSound folder in your application-data folder to remove
    them as well.

7.6 Children and third parties
    The software is not directed at children, and because nothing is
    collected, nothing is shared or sold to third parties.
